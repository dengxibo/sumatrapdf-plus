# SumatraPDF Plus 3.7.110

修复“保存图像”窗口首次打开时 PNG 等格式下拉框偏矮的问题。应用主题后会重新对齐格式框和同排按钮。

**新用户请先到 [3.7.107 发布页](https://github.com/dengxibo/sumatrapdf-plus/releases/tag/3.7.107)下载完整包，解压后用本版 SumatraPDF-Plus.exe 替换同名文件。** 已有完整程序目录的用户退出程序后替换 EXE 即可。

Fix the image format selector height when the Save Image window first opens. New users should download a complete package from [3.7.107](https://github.com/dengxibo/sumatrapdf-plus/releases/tag/3.7.107), extract it, and replace its EXE with this release's executable.
