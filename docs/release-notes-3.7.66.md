# SumatraPDF Plus 3.7.66

## 中文

- Markdown 内置原生 Mermaid 图表渲染，支持中文和多行节点标签，无需额外 DLL、浏览器或 JavaScript；渲染失败时保留代码。
- 修复 Mermaid 多行节点文字重叠的问题。
- 修复 Word 中文文字误用复杂文字字号而缩小的问题，恢复公文的 VML 艺术字红头和线条。
- 修复 Markdown / HTML 刷新排版后重建标题目录时可能发生的崩溃。

[下载 Windows x64 EXE](https://github.com/dengxibo/sumatrapdf-plus/releases/download/3.7.66/SumatraPDF-Plus.exe)。退出程序后替换完整安装目录中的 EXE，保留配置及配套文件。Mermaid 功能已链接进 EXE，不需要 `sumatra_mermaid.dll`。

## English

- Add built-in native Mermaid rendering for Markdown, including Chinese text and multiline labels. No additional Mermaid DLL, browser, or JavaScript runtime is required; failed diagrams retain their source.
- Fix overlapping multiline Mermaid node labels.
- Fix Chinese Word text incorrectly using complex-script font sizes, and render straight VML WordArt letterheads and rules.
- Fix a crash when rebuilding Markdown/HTML heading outlines after reflow.

[Download Windows x64 EXE](https://github.com/dengxibo/sumatrapdf-plus/releases/download/3.7.66/SumatraPDF-Plus.exe). Close the application before replacing the EXE in an existing complete installation; retain settings and supporting files.
