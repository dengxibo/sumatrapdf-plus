# SumatraPDF Plus 3.7.80

## 中文

- 修复上层对话框被底层目录分隔条影响的问题：鼠标悬停不再误显示双箭头，按钮点击不再被截获为分隔条拖动。
- 修复关闭 PDF 或切换文档后选区浮动工具条残留的问题；命令面板中的具体电子书字体名称仅在重排电子书中显示（#119）。

[下载 Windows x64 EXE](https://github.com/dengxibo/sumatrapdf-plus/releases/download/3.7.80/SumatraPDF-Plus.exe)。退出程序后替换完整安装目录中的 EXE，保留配置及配套文件，重启后生效。

## English

- Fix the sidebar splitter interfering with overlaid dialogs: hovering no longer shows the resize cursor, and button clicks are no longer intercepted as splitter drags.
- Hide the selection toolbar when closing or switching documents, and show individual ebook font families in the command palette only for reflowable ebooks (#119).

[Download Windows x64 EXE](https://github.com/dengxibo/sumatrapdf-plus/releases/download/3.7.80/SumatraPDF-Plus.exe). Close the application before replacing the EXE; retain settings and supporting files, then restart.
