# SumatraPDF Plus 3.7.75

## 中文

- 同版本更新：修复剪刀图标在暗黑模式下边缘发白、显粗的问题。已下载旧附件的用户可重新下载替换。

- PDF 导出图片提供当前页、指定连续范围和全部页面三个选项；默认选择指定范围，支持如 `30-45` 的输入，并显示有效页码及校验提示。
- 导出对话框的路径及页码范围文字垂直居中。
- 批注工具旁新增细线剪刀“区域截图”按钮，点击后拖选文档区域即可预览、保存图片，按 Esc 取消（#115）。
- 截图按钮跟随批注工具一起显示、隐藏，窄窗口下不单独放入“更多工具”；原有 Shift+Alt+拖选继续可用。

[下载 Windows x64 EXE](https://github.com/dengxibo/sumatrapdf-plus/releases/download/3.7.75/SumatraPDF-Plus.exe)。退出程序后替换完整安装目录中的 EXE，保留配置及配套文件，重启后生效。

## English

- Same-version update: fix pale, heavy antialiasing around the scissors icon in dark mode. Download and replace the EXE again if you installed the earlier attachment.

- Export PDF images from the current page, one continuous range, or all pages. Range export is selected by default, with examples and page-number validation.
- Vertically center folder paths and page-range text in the export dialog.
- Add a small scissors button beside the annotation tools to capture a document region, preview it, and save it. Press Escape to cancel (#115).
- Show and hide the capture button with annotation tools, without a separate More tools entry in narrow windows. Shift+Alt+drag remains available.

[Download Windows x64 EXE](https://github.com/dengxibo/sumatrapdf-plus/releases/download/3.7.75/SumatraPDF-Plus.exe). Close the application before replacing the EXE; retain settings and supporting files, then restart.
