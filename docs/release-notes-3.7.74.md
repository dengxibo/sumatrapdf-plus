# SumatraPDF Plus 3.7.74

## 中文

- Markdown（.md / .markdown）支持工具栏 A+ / A− 调整字号，按文件记忆，并可右键恢复默认字号。
- 标题、正文和代码按比例缩放，保留相对字号和原有排版风格。

[下载 Windows x64 EXE](https://github.com/dengxibo/sumatrapdf-plus/releases/download/3.7.74/SumatraPDF-Plus.exe)。退出程序后替换完整安装目录中的 EXE，保留配置及配套文件，重启后生效。

## English

- Adjust Markdown (.md / .markdown) font sizes using the toolbar A+ / A− buttons, with per-file size memory and a right-click option to restore the default.
- Scale headings, body text, and code proportionally while preserving their relative sizes and existing typography.

[Download Windows x64 EXE](https://github.com/dengxibo/sumatrapdf-plus/releases/download/3.7.74/SumatraPDF-Plus.exe). Close the application before replacing the EXE; retain settings and supporting files, then restart.
