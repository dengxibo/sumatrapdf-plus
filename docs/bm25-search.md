# BM25 相关搜索

在工具栏查找框输入关键词，点击省略号打开“详细搜索”，点击 **BM25 图标**启用相关搜索。图标左侧为 B，右上为 25、右下为 m，采用与大小写、全词匹配一致的细线和主题颜色，按钮尺寸及选中、悬停样式也与它们一致。再次点击恢复精确查找。该开关只用于本次运行，不保存到配置。

相关搜索返回最多 100 个候选段落，按相关度排列。点击结果或使用上一条、下一条跳转；选中的是候选段落，不代表整段都是关键词的精确匹配。相关模式忽略大小写，不使用“匹配整个单词”开关。

中文单字用于找回简称和全称之间的部分共同内容，连续双字用于提高相同措辞的排名。英文按完整单词匹配。评分采用 BM25 的词频、逆文档频率和段落长度归一化，要求候选覆盖至少 60% 的查询单字或单词。完整连续词序适当加分。结果预览从相关词附近开始，过长片段在切分边界保留重叠，并合并重复定位的结果。

适合输入短关键词（最多 64 个不同检索项，包括中文双字）；超过限制时显示“Shorten query”，提示缩短关键词，不会静默截取查询。

它没有同义词库、语义模型或网络调用；不能保证理解所有简称，也不会自动纠正 OCR 错字。只有图片而没有可搜索文字的页面仍需先完成 OCR。首次查询需要扫描可用文字，长文档可能较慢；输入新词会取消旧查询。

建议比较以下查询：

- “社保卡”：正文中的“社保卡”和“社会保障卡”都应有机会出现；检查“银行卡”等候选是否过多。
- “社会保障卡”：检查正文“社保卡”是否出现在相关结果中；其他简称仍可能因覆盖不足而不出现。
- 原文中的完整词句：比较精确搜索和相关搜索的结果数量、排名及跳转。
- 中文跨行文字、英文多词、无关关键词：检查换行、整词匹配和误报。
- 连续快速改词、关闭窗口、切换文档：检查取消与结果隔离。

关闭 Bm25 开关即可继续使用原精确查找。当前实现独立于 TOC 校准的 BM25，不修改目录提取行为。
