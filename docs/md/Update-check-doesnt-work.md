# Update check doesn't work?

A new version of Sumatra has been released, you use the `Help -> Check for updates` menu and it didn't notify about a new release. Is this a bug?

Release builds normally check once a day when automatic checks are enabled. They also continue checking while the program remains open. Pre-release builds check once a week.

If you decline a particular version, SumatraPDF waits seven days before prompting for that version again. A newer version is offered immediately, and a manual check bypasses the delay.

Plus 3.7.3 used the wrong update source. Plus 3.7.4 also skipped users who had never checked before. Those versions cannot be repaired remotely, so affected users must download a current release manually once.
