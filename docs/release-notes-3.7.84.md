# SumatraPDF Plus 3.7.84

## 中文

- 修复文字版 PDF 下划线、波浪线偏低的问题，改按文字基线定位；下划线与波浪线中心对齐，中文保留字形底部间距。
- 英文删除线按字体 x 高度中心定位。
- 文字版 PDF 的线宽、波幅和波长按字号计算；项目圆点跟随同一行正文，修复 Wingdings 圆点标注明显偏细、偏小的问题。

以上调整适用于新建标注，已有标注不自动修改。扫描 PDF 保留现有处理方式。

[下载 Windows x64 EXE](https://github.com/dengxibo/sumatrapdf-plus/releases/download/3.7.84/SumatraPDF-Plus.exe)。退出程序后替换完整安装目录中的 EXE，保留配置及配套文件，重启后生效。

## English

- Position native PDF underlines and squiggles relative to the text baseline. Align straight underlines with the center of squiggles and preserve clearance below CJK glyphs.
- Position Latin strikeouts at the font's x-height center.
- Derive stroke width and wave dimensions from font size. Match list markers to the neighboring body text, including private-use Wingdings bullets.

These changes apply to new annotations. Existing annotations and scanned-PDF placement are unchanged.

[Download Windows x64 EXE](https://github.com/dengxibo/sumatrapdf-plus/releases/download/3.7.84/SumatraPDF-Plus.exe). Close the application before replacing the EXE; retain settings and supporting files, then restart.
