# SumatraPDF Plus 3.7.36 (2026-10-02)

### What's new

**Selection translate and Ask AI** — The selection toolbar has Translate and Ask AI. Translate prefers Volcengine and falls back to the AI API for a translation only. Ask AI answers in the app when an API is configured, and still opens the web chat when it is not. The panel can be dragged and resized, copies the translation, renders Markdown, and follows all four themes. The answer is two points larger than the UI font. Options splits OCR and AI; the model field is a plain box plus Choose, with search, and speech, image, and embedding models are left off the list.

**Selection** — Copy clears the highlight. Closing Lookup, Translate, or Ask AI clears the selection those windows were opened with.

**Dark mode** — High-key photos (fog, snow, white fur) keep their tones. Pale cut-out edges (glass rims, eggshells, sweater cuffs) stay in color instead of turning into black blocks. Side-by-side cut-outs are no longer clipped against each other. A textbook's full-page cream plate becomes the theme background.

**Read Aloud** — The bar can be dragged for the current session. Speed is a menu from 0.25× to 2×. Follow is translated. An in-page speaker starts or restarts playback and does not stop it. Embedded PDF audio uses the same bar.

**Also** — Changing the EPUB font size stays on the current line. Continuous zoom keeps the page anchor. Matrix brackets from subset Symbol fonts render again ([#35](https://github.com/dengxibo/sumatrapdf-plus/issues/35)). Scanned pages with no text layer are OCR'd by default when the setting has not been saved.

### 本版更新

**划词翻译和问问 AI** — 选区工具栏有「翻译」和「问问 AI」。翻译优先火山，失败时用已配置的 AI 只出译文。已配置 API 时问问 AI 在应用内回答，未配置仍打开网页。浮层可拖动、调大小、复制译文、按 Markdown 显示，并跟随四种主题。译文和回答比界面字体大 2 磅。选项里 OCR 与 AI 分成两页；模型是输入框加「选择」，可搜索，语音、图片和向量模型不列入名单。

**选区** — 点「复制」后高亮消失。关掉查词、翻译或问问 AI 后，打开它们时的那一段选区也会消失。

**暗色** — 雾、雪、白毛这类高调照片保持连续色调。玻璃杯沿、蛋壳、毛衣袖口这类淡色抠图边缘不再被切成黑块。并排抠图不再互相裁切。教材整页奶油色底图换成主题背景。

**朗读** — 朗读条本次打开期间可以拖走。倍速改为菜单，0.25× 到 2×。「跟随」有中文。页内喇叭只负责开始或重放，不负责停止。带内嵌录音的 PDF 也用这条朗读条。

**其他** — EPUB 改字号停在当前行。连续模式缩放保持页面锚点。子集 Symbol 字体的矩阵括号恢复正常（[#35](https://github.com/dengxibo/sumatrapdf-plus/issues/35)）。没有保存过这项设置时，无文字层的扫描页默认自动 OCR。

### Upgrade

Exit the app completely, then replace `SumatraPDF-Plus.exe`. Do not overwrite official `SumatraPDF.exe`.

### 升级说明

便携版：先完全退出程序，再替换 `SumatraPDF-Plus.exe`。不要覆盖官方的 `SumatraPDF.exe`。
