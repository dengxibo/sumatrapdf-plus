# SumatraPDF Plus 3.7.21 (2026-08-01)

**Download:** [SumatraPDF.exe](https://github.com/dengxibo/sumatrapdf-plus/releases/download/3.7.21/SumatraPDF.exe) (portable x64)

Full release page (EN + 中文): [docs/releases/3.7.21.md](https://github.com/dengxibo/sumatrapdf-plus/blob/main/docs/releases/3.7.21.md)

---

### Highlights

1. **Ebook fonts** — Settings → **字体**: Western + CJK body fonts for EPUB/MOBI (bundled or installed).
2. **Third-party fonts** — WPS/Kingsoft registry paths now load in EPUB.
3. **Bilingual EPUB** — English uses Western font; Chinese uses CJK font.
4. **CSS override** — reader font choice overrides publisher `font-family` on body elements.
5. **Font menu** — wheel scroll, Chinese labels, filter UI/symbol fonts.

### 本版更新

1. **电子书字体** — 设置 →「字体」：EPUB/MOBI 西文/中文正文字体（内置或系统）。
2. **第三方字体** — WPS/金山等注册表路径字体可在 EPUB 中生效。
3. **双语 EPUB** — 英文西文字体、中文中文字体（修复书虫英文变楷体）。
4. **覆盖书籍 CSS** — 更改阅读字体后强制覆盖段落字体。
5. **字体菜单** — 滚轮滚动、中文标签、过滤 UI/符号字体。
