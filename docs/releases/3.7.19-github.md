# SumatraPDF Plus 3.7.19 (2026-07-28)

**Download:** [SumatraPDF.exe](https://github.com/dengxibo/sumatrapdf-plus/releases/download/3.7.19/SumatraPDF.exe) (portable x64)

Full release page (EN + 中文): [docs/releases/3.7.19.md](https://github.com/dengxibo/sumatrapdf-plus/blob/main/docs/releases/3.7.19.md)

---

### Highlights

1. **Math / vector symbols** — fix operator and matrix-bracket glitches in textbook PDFs.  
2. **Text selection** — CJK/EPUB/formula selection and highlight improvements.  
3. **PDF links** — jump to DOI and URI links without waiting for full page parse.  
4. **Theme & color mode** — faster, stabler EPUB reflow when switching theme or document colors.

### 本版要点

1. **向量运算与公式符号** — 修复教材 PDF 运算符、矩阵括号等显示错乱。  
2. **划词选区** — 改进中文/EPUB/公式划词与高亮。  
3. **PDF 链接** — 外链可及时识别并跳转。  
4. **主题与色彩模式** — 切换更快、更稳，减轻 EPUB 首次切换空白。
