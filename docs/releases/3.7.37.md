## What's new

**Sidebar** — The title has Bookmarks, Thumbnails, and Favorites. One click switches the column, and the choice is remembered per document. All three can be searched. Bookmarks and thumbnails share one title search, so switching keeps the text and the matching pages. Favorites filter by name. A thumbnail click jumps to that page, and the tag is the page number alone. Colors follow the open document. Favorites use the same hover and selection as bookmarks in all four themes: full-row fill, a dark-theme selection box, and no system blue highlight. Opening Favorites does not select the first row. Plus adds the current page; minus removes that page's favorite, or the highlighted row when one is selected. The close mark closes the column from bookmarks, thumbnails, and favorites. Dragging the splitter fills the newly uncovered strip immediately.

**Home** — A right-click opens a menu. Ctrl+click toggles, Shift+click selects a range, and Ctrl+A selects every file. With the search box focused, Ctrl+A still selects only the search text. Delete File asks once, in the current language, then moves the file to the Recycle Bin. Cancel does nothing. Remove From History and Del do not ask. Selection boxes stay inside their row, include the left and top edges, and sit a little farther out from a cover's gray shadow. In light themes the box is a muted slate blue.

**Read aloud** — Choosing another bookmark stays on that page. The Follow button on the read-aloud bar returns to the spoken place.

**EPUB** — Full-page comic panels, such as in the Bookworms omnibus, each stay on their own page, with no blank page between them.

**Translate** — When Volcengine Translate and the AI API are not set up, translating a selection sends it to the web AI. An authorization failure does the same. A real network failure still shows the error. Valid keys still translate in the app.

**Also** — Settings → Reading Font opens Western and CJK body fonts in a dialog with a title bar, a search box, a font list, and OK and Cancel. A click selects a row; OK or a double-click applies it. Each row is drawn in that font. Options defaults Lazy-load inactive tabs off. In single-page view, a right-click in the blank area beside the page shows the same menu as a click on the page, including that page's favorite and creating an annotation at the cursor. Collapsing or expanding a bookmark keeps the dark-theme selection box around the whole row. A bookmark tip appears only when the title is cut off.

## 本版更新

**侧栏** — 标题左侧是书签、缩略图、收藏。点一个就在同一栏里切换，选择记在这份文档上。三种都有搜索。书签和缩略图共用一次按标题的搜索，切换时文字和筛出来的页都留着。收藏按名称另筛。点缩略图跳到那一页，页码只标数字，颜色跟当前正文的主题走。收藏的悬停和选中在四种主题下都跟书签同一套：整行底色、暗色选中框，文字不改成系统蓝底白字。打开收藏不会自动圈住第一行。加号把当前页加入收藏，减号去掉当前页的收藏；选中了某一条时减号删这一条。关闭叉在书签、缩略图、收藏下都关掉这一栏。向右拖分隔条时，新露出的一竖条会马上用侧栏底色补上。

**主页** — 右键会弹出菜单。Ctrl+单击加减、Shift+单击连选、Ctrl+A 全选。搜索框有焦点时 Ctrl+A 仍只选中搜索文字。删除文件先按当前语言确认，文件进入回收站。取消则不动。「从历史记录删除」和 Del 不确认。选中框留在本行内，左边和第一行上边都会画上，封面选中框离开灰色阴影。明亮主题下选中框是低饱和的灰蓝。

**朗读** — 朗读时点其他目录条目会留在那一页。要回到朗读位置，用朗读条上的跟随按钮。

**EPUB** — 书虫这类整页漫画，每一幅图单独成页，图和下一幅之间不再夹一页空白。

**翻译** — 没配火山翻译或 AI 接口时，划词翻译发给网页 AI。密钥被拒绝时也一样。真正的网络失败仍显示错误。密钥有效时仍在应用内翻译。

**其他** — 设置 → 阅读字体里的西文、中文正文字体，改成带标题栏、搜索框、字体名单、确定和取消的对话框。单击只选中，确定或双击才换字体。每一行用该字体画自己的名字。选项里「延迟加载未激活的标签页」默认关闭。单页显示时，在页面两侧空白处右键，菜单与点在纸面上相同。折叠或展开书签后，暗色选中框仍框住整行。书签提示只在标题被栏截断时出现。
