# SumatraPDF Plus 3.7.23 (2026-08-04)

### What's new

**PDF smart dark mode** — fix inverted colors on RAZ picture-book pages by classifying large images as photo/illustration vs scanned page background.

**Embedded PDF audio** — play Sound, RichMedia, and Screen annotations (e.g. RAZ speaker icons) from embedded MP3 assets in the PDF; no network required.

**Media annotation UX** — click to play only; no Ctrl+click edit, no hover tooltip, excluded from the annotation editor list.

### 本版更新

**PDF 智能暗色模式** — 修复 RAZ 绘本页面颜色反转：区分插图/照片与扫描页背景，插图保持正常色彩。

**PDF 内嵌音频** — 支持播放 Sound、RichMedia、Screen 注释（如 RAZ 扬声器图标），从 PDF Assets 读取 MP3，无需联网。

**媒体注释交互** — 单击即播放；不支持 Ctrl+单击编辑、无悬停提示，且不出现在注释编辑列表中。
