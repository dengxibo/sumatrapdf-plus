### What's new

**Match theme** — Soft studio photo books (RAZ Getting Dressed and similar) stay on the picture-book path instead of line-art binarize, so dark hair is no longer painted theme-white. Zoo-style animal cards still knock out the white mat; light scales and fur AA no longer abort the cutout back to a white rectangle. Foam highlights, filled scenes, and oval photos are protected from an over-eager interior flood.

**PDF icons** — The Explorer PDF file icon uses the same sash-style `pdf-32bit` artwork as epub/chm, so small sizes stay readable (issue #83).

**AI TOC** — Optional web AI API profiles; API keys are stored with Windows DPAPI. AutoOcrOn and related settings are in the options. Footer buttons size to their translated labels, and the dialog shows the app icon.

**Page wheel** — In continuous fit-page view, wheel-up opens the bottom of the previous page instead of staying on the current page.

**Smart invert** — Face paste uses padded landmark bounds so profile and looking-down faces keep coverage. Layout textbooks skip heavy photo remaps; far TOC jumps prioritize the visible page.

**OCR release** — Copying the OCR sidecar for release builds also copies the face-model files.

### 本版更新

**跟随主题** — RAZ 影棚绘本（如 Getting Dressed）走绘本路径，不再被当成连环画；黑发不再被涂成主题白。动物园一类白卡动物图继续抠白底；浅色鳞片和毛边不会把整张卡退回白矩形。泡沫高光、填色场景和椭圆照片也不会被内部 flood 啃掉。

**PDF 图标** — Explorer 里 PDF 关联图标改用与 epub/chm 同风格的 `pdf-32bit` 色带图标，小尺寸更清晰（issue #83）。

**AI 目录** — 可配置网页 AI API，密钥用 Windows DPAPI 存放；新增 AutoOcrOn 等相关设置。对话框底栏按钮按翻译文案加宽，并显示应用图标。

**滚轮翻页** — 连续适合页面时，向上滚轮翻到上一页底部，不再停在当前页。

**智能反色** — 人脸粘贴用带边距的 landmark 框，侧脸与低头也不再留下反色缺口。教材布局大图跳过重 remap；远距离目录跳转优先渲染当前页。

**OCR 发布** — 发布构建复制 OCR 侧车时一并带上人脸模型。
