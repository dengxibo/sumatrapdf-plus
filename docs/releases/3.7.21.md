## Highlights / 本版更新

1. **Ebook fonts** — Settings menu **字体** (after Theme): choose Western and CJK body fonts for EPUB/MOBI from bundled `fonts\` or installed Windows fonts.  
   **电子书字体** — 设置菜单新增「字体」（位于主题之后）：为 EPUB/MOBI 选择西文/中文正文字体（内置或系统已安装）。

2. **Bundled reader fonts** — Literata, Source Serif 4, Source Han Serif SC, LXGW WenKai (place files under `fonts\` next to the exe).  
   **内置阅读字体** — Literata、Source Serif 4、思源宋体、霞鹜文楷（将字体文件放在 exe 旁 `fonts\` 目录）。

3. **Third-party installed fonts** — fonts registered outside `%WINDIR%\Fonts` (e.g. WPS/Kingsoft) now resolve in EPUB reflow.  
   **第三方已安装字体** — 注册表中的非系统 Fonts 路径（如 WPS/金山）可在 EPUB 重排中加载。

4. **Bilingual EPUB** — English uses the Western font; Chinese uses the CJK font (fixes 书虫-style books showing English in Kai).  
   **双语 EPUB** — 英文用西文字体、中文用中文字体（修复书虫等双语书英文显示为楷体的问题）。

5. **Publisher CSS override** — when you change reader fonts, override embedded `font-family` on paragraphs and calibre classes.  
   **覆盖书籍 CSS** — 更改阅读字体后，强制覆盖段落与 calibre 类上的 `font-family`。

6. **Font menu UX** — mouse wheel scroll on long font lists; Chinese labels for common installed CJK families; filter UI/symbol fonts.  
   **字体菜单** — 长列表支持滚轮；常见中文字体显示中文名；过滤 UI/符号字体。
