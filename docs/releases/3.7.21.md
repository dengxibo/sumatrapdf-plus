## What's new / 本版更新

**Reading font settings (EPUB/MOBI)** — **Settings** menu → **Reading Font**: choose **Western Body Font** and **CJK Body Font** separately. In each font list, fonts above the separator line come from the `fonts\` folder next to the executable; fonts below the line are installed on your system.

**阅读字体设置（EPUB/MOBI）** — **设置**菜单 → **字体**：可分别选择 **西文字体** 与 **中文字体**。每个字体列表中，横线上方来自程序旁 `fonts\` 文件夹，横线下方为系统已安装字体。

## Upgrade notes / 升级说明

**English**

- *About* and the built-in update check (if enabled) report **3.7.21**.
- For portable copies, exit SumatraPDF completely before replacing the executable.
- **Delete `SumatraPDF-settings.txt` before first run** (portable: next to `SumatraPDF.exe`; installed: `%LOCALAPPDATA%\SumatraPDF\SumatraPDF-settings.txt`). Restart to create a new settings file.

**中文**

- 「关于」与内置更新检查（若开启）将显示 **3.7.21**。
- 便携版请先完全退出，再替换程序。
- **首次运行前请删除配置文件**（便携版在 exe 同目录；安装版在 `%LOCALAPPDATA%\SumatraPDF\SumatraPDF-settings.txt`），重启后会重新生成。
