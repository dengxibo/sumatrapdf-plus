# SumatraPDF Plus 3.7.30 (2026-08-25)

Full release page: [docs/releases/3.7.30.md](https://github.com/dengxibo/sumatrapdf-plus/blob/main/docs/releases/3.7.30.md)

### What's new

**Home** — Thumbnail cards can pin or remove; right-click for Open / Show in folder / Pin / Remove; empty canvas can drop missing local files (USB/network skipped). Thumbs grow or shrink slightly to fill the window. List view uses two-line rows, covers fill the thumb box, and the header sits on one baseline.

**Open** — Landscape 图解/PPT PDFs with `/PageLayout /TwoPageRight` no longer start in book view. Fixed-layout EPUB covers layout at the real viewport and open with fit-width.

**Dark match-theme** — Word 红头/标题 that are a 2×2 color chip plus a glyph SMask remap like ink.

**Extract bookmarks / save** — Born-digital PDFs parse the printed Contents in the front and stop. Saving a PDF that cannot be overwritten writes a sidecar and replaces after close. Save searchable PDF no longer blanks text-only pages.

**Fullscreen** — Ctrl+Tab document switcher and Alt+Tab work again.

### 本版更新

**首页** — 缩略图可钉住/删除；右键打开、在文件夹中显示、钉住、从历史删除；空白处可清掉丢失的本地文件（U 盘/网络盘不算）。缩略图略微伸缩铺满窗口。列表两行显示，封面铺满缩略图格，顶栏对齐。

**打开** — 横版图解/PPT 若带了双页目录标记，不再一进来就是书籍模式。固定版式 EPUB 封面按真实 viewport 排，打开时用适合宽度。

**深色「匹配主题」** — Word 红头/标题若是 2×2 色块加字形软遮罩，按墨色重映射。

**提取目录 / 保存** — 电子书只从前部印刷目录取书签。原文件被占用时先写到旁边再替换。保存可搜索 PDF 不再把纯文字页存成空白。

**全屏** — Ctrl+Tab 文档切换和 Alt+Tab 恢复可用。

### Upgrade

Exit the app completely, then replace `SumatraPDF-Plus.exe`. Do not overwrite official `SumatraPDF.exe`.

### 升级说明

便携版：先完全退出程序，再替换 `SumatraPDF-Plus.exe`。不要覆盖官方的 `SumatraPDF.exe`。
