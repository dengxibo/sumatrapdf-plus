## What's new

**PDF dark mode remaps colors instead of inverting** — dark **Match theme** maps paper and ink onto the theme palette (paper → background, ink → text). Pages are no longer photographic negatives; text stays readable and colorful illustrations keep their original hues.

**Annotations & TOC** — toolbar one-click rectangle / ellipse / line / ink (`ShowAnnotToolbarButtons = false` to hide); bookmark and favorite titles wrap by default (`TreeWrapLabels`).

**Join split images** — Calibre-style thin-strip duplicate pages are joined in continuous view (`JoinSplitPdfImages`).

**Match theme & loading** — light **Match theme** keeps colorful covers; oversized or duplicate “Loading …” banners are fixed.

**Session & large documents** — last session restores correctly; `ReloadModifiedDocuments` works for EPUB; switching or closing tabs on large files no longer stalls for 10+ seconds.

**Find** — Results are numbered in document order; the first jump starts from the current page, Enter continues from the current page, F3 / Next / Prev step from the current hit. The list stays still while the count updates, and the selected row is clearer in dark themes.

## 本版更新

**PDF 暗黑模式改为换色，不再反色** — 暗色「匹配主题」把纸面和油墨映射到主题色（纸→背景、墨→文字），而不是整页反成负片。文字仍然清晰，彩色插图保留原色。

**标注与目录** — 工具栏可一键画矩形 / 椭圆 / 直线 / 画笔（`ShowAnnotToolbarButtons = false` 可隐藏）；书签与收藏长标题默认多行换行（`TreeWrapLabels`）。

**自动拼接** — Calibre 类「同图细条重复页」默认接成连续图（`JoinSplitPdfImages`）。

**匹配主题与载入** — 浅色「匹配主题」下彩色封面保留原色；「载入…」不再字号过大或出现两条。

**会话与大型文档** — 退出后再打开会正常恢复上次标签；`ReloadModifiedDocuments` 对 EPUB 生效；大型文件切换 / 关闭标签不再卡十几秒。

**查找** — 结果按全书顺序编号；首次跳转从当前页起，Enter 从当前页续搜，F3 / 上一个 / 下一个从当前命中继续。计数刷新时列表不抖，暗色下选中行更清楚。

便携版升级前请先完全退出程序。
