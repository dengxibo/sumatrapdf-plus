### What's new

**PDF table of contents editing** — create, rename, retarget, delete, reorder, and change hierarchy; outline styling is preserved and saved with other PDF changes.

**PDF 目录编辑** — 可创建、重命名、修改目标、删除、排序和调整层级；目录样式与其他 PDF 修改一并保存。

**Ebook font size** — toolbar **Decrease Font Size** / **Increase Font Size** for reflowable EPUB/MOBI (2 pt steps, 6–26); progress notification during relayout.

**电子书字号** — 可重排 EPUB/MOBI 增加工具栏缩小/放大字号（每次 2 磅，6–26）；重排时显示进度通知。

**Search and selection** — fix cumulative search highlight drift on reflow EPUB; improve vertical EPUB selection, lookup, and search alignment; rescan after progressive reflow completes.

**搜索与划词** — 修复可重排 EPUB 搜索高亮逐段错位；改进竖排划词、查词与搜索对齐；渐进加载完成后重新搜索。

**Image context menu** — restore **Copy To Clipboard** on PDF images; full **Image** submenu on EPUB and other formats.

**图片右键菜单** — PDF 图片恢复「复制到剪贴板」；EPUB 等格式支持完整「图像」子菜单。

### Upgrade

Exit SumatraPDF completely before replacing the portable executable. Reopen reflowable ebooks after upgrading so page text caches refresh.

便携版请先完全退出，再替换程序。升级后请重新打开可重排电子书，以刷新页面文本缓存。
