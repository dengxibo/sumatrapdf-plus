### What's new

**Read Aloud** — One speaker button, one bottom bar, one Settings → Read Aloud page (voice, speed, highlight, follow, narrated books). EPUB 3 books with recorded narration play that audio; otherwise text-to-speech. Play becomes Pause while speaking; speed applies immediately. TTS never shows ±10 s, so the bar does not jump between play and pause.

**EPUB 3 narration** — Start from the current page or cursor only if that location has audio; later chapters without overlays use TTS from here. The highlight follows the current word inside each SMIL phrase. Speed includes 0.5×. Remote URLs are not played.

**Fixed-layout EPUB** — Pages appended during progressive load are no longer 0×0 (e.g. SVG). Smooth scrolling no longer spins on an unreachable target.

**Ctrl+wheel** — `ZoomIncrement = 0` steps through `ZoomLevels` again.

**Extract TOC** — After typing page numbers when no printed TOC was found, the web AI API button is enabled.

**Match theme** — Fat scanned titles go to theme white again, without undoing photo hair protection.

### 本版更新

**朗读** — 喇叭、菜单「朗读」和底部朗读条是同一套控制。设置里新增「朗读」页。书里有录音就放录音，没有就用系统语音。播放中显示暂停；点倍速立刻生效。TTS（含暂停）不显示 ±10 秒。

**EPUB 3 有声书** — 从当前页/光标开始：有录音才放录音，没有就从这里 TTS，不跳回第一章。SMIL 一段里按词高亮。倍速含 0.5×。远程地址不放。

**固定版式 EPUB** — 渐进加载追加的页不再是 0×0（如 SVG 页）。

**Ctrl+滚轮** — `ZoomIncrement = 0` 再次按 `ZoomLevels` 步进。

**提取目录** — 手动输入页码后，网页 AI API 按钮也可点。

**跟随主题** — 扫描标题不再留下色块；照片里的黑发仍不涂成主题白。
