# SumatraPDF Plus 3.7.28 (2026-08-17)

### What's new

**Match-theme portraits & picture books** — oval portraits keep a small mat halo so poles are not cut into rectangular bars; inset photos no longer leave a white hairline against body text; thick titles on paper invert to theme text; color RAZ pages that look like line-art in the thumbnail stay on the picture-book path (cream 连环画 still inverts as line art).

**Reading UI** — Ctrl+wheel zoom uses a steady ~10% step and no longer jumps to 6400% or 20%; TOC splitter live-drag no longer relayouts the page or jumps the search row; toolbar fullscreen button (F11).

**EPUB & Windows 11** — ink in single-page view stays on its page; fullscreen no longer leaves the taskbar volume icon on top of the window.

### 本版更新

**匹配主题肖像与绘本** — 椭圆肖像衬纸光晕缩小，两极不再被啃成方块；嵌入照片与正文交界不再留白竖线；纸面上的粗标题反成主题文字色；缩略图像线稿的彩色 RAZ 页走绘本路径（泛黄连环画仍按线稿反色）。

**阅读界面** — Ctrl+滚轮每格约 10%，不再一甩到 6400% 或 20%；拖 TOC 分隔条不再重排页面或让搜索行跳动；工具栏增加全屏按钮（F11）。

**EPUB 与 Windows 11** — 单页模式下墨迹只留在所属页；全屏后任务栏喇叭图标不再盖在窗口上。
