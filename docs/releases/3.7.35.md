## What's new

**Read Aloud** — One speaker button, one bottom bar, one Settings → Read Aloud page (voice, speed, highlight colour, auto-follow, narrated-book options). EPUB 3 books with recorded narration play that audio; otherwise text-to-speech is used. Play becomes Pause while speaking; a speed tap applies immediately. On a TTS chapter the bar never shows ±10 s, so play and pause stay the same width.

**EPUB 3 narration** — When the book ships Media Overlays, Play starts the recording at the current page or cursor if that location has audio; later chapters without overlays use TTS from here (no jump back to chapter 1). The highlight follows the current word inside each SMIL phrase (letter/character-weighted time). Word-level SMIL is unchanged. Speed includes 0.5×. Missing audio files fall back to TTS; font-size change keeps the place; remote URLs are not played.

**Fixed-layout EPUB** — A page appended during progressive loading is no longer laid out as 0×0 (e.g. SVG pages). Smooth scrolling no longer spins on an unreachable target.

**Ctrl+wheel** — `ZoomIncrement = 0` (default) steps through `ZoomLevels` again; a positive value uses that percent relative zoom.

**Extract TOC** — After typing page numbers when no printed TOC was found, the web AI API button is enabled.

**Match theme** — Fat scanned titles go to theme white again, without undoing photo hair protection.

## 本版更新

**朗读** — 工具栏喇叭、菜单栏「朗读」和底部朗读条是同一套控制。设置里新增「朗读」页（语音、语速、高亮色、自动跟随、有声书）。书里有录音就放录音，没有就用系统语音。播放中显示暂停图标；点倍速立刻生效。系统语音朗读（含暂停）不显示 ±10 秒，条不会跳动。

**EPUB 3 有声书** — 从当前页或光标处开始：这一处有录音才放录音，后面没有录音的章节用系统语音从这里读，不再跳回第一章。SMIL 一段里按词高亮（按字母/汉字分时间）。词级 SMIL 不变。倍速含 0.5×。录音文件缺失的句子改用系统语音；调字号保留位置；远程地址不放。

**固定版式 EPUB** — 渐进加载时追加的页面不再排成 0×0（如 SVG 页）；平滑滚动遇到无法到达的目标不再空转。

**Ctrl+滚轮** — `ZoomIncrement = 0`（默认）再次按 `ZoomLevels` 档位步进；大于 0 时按该百分比相对缩放。

**提取目录** — 没找到印刷目录、自己输入页码后，网页 AI API 按钮也可点。

**跟随主题** — 扫描标题上的色块不再被当成照片头发保护而留下；照片里的黑发仍然不涂成主题白。

便携版升级前请先完全退出程序。
