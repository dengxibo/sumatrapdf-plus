# SumatraPDF Plus 3.7.24 (2026-08-04)

### What's new

**Chinese dictionary TTS** — speaker button for Chinese lookups; polyphone tabs (e.g. 鞘 qiào / shāo) speak the selected reading via SSML; no duplicate pinyin line when tabs are shown; optional `tts-pronunciation.json` for read-aloud overrides.

**PDF Match-theme dark mode** — colorful picture-book art keeps natural colors with grey paper softening; only true paper scans are AdaptiveDocument-recolored; text-heavy literature keeps OKLab remapping.

**Screen annotation audio** — play embedded MP3 from `/A` Rendition → Media Clip `/D` (e.g. RAZ-AA *The City*).

### 本版更新

**中文词典发音** — 查词弹窗支持喇叭朗读；多音字切换拼音标签（如 鞘 qiào / shāo）按所选读音朗读；有拼音标签时不再重复显示一行拼音；可选 `tts-pronunciation.json` 纠正全文朗读读音。

**PDF 匹配主题暗色** — 绘本彩色插图保留原色、纸面柔化为灰；仅对真扫描页重着色；文字类文学书继续 OKLab 重映射。

**Screen 注释音频** — 支持 `/A` Rendition 动作中的 Media Clip 内嵌 MP3（如 RAZ-AA《The City》）。

### Upgrade

Exit SumatraPDF completely before replacing the portable executable.

### 升级说明

便携版请先完全退出，再替换程序。
