# SumatraPDF Plus 3.7.38 (2026-10-04)

### What's new

**Handwritten signature** — Draw it once from the toolbar or the page menu, then hold and drag to set the size. It is selected as soon as it is placed, so it can be moved or resized. Click empty page to leave edit mode. A click selects it, the same as other annotations, without holding Ctrl. Ctrl+click still opens the annotation editor. The toolbar button is a quill. A phone photo works too: pick a file, paste, or drag one in from WeChat. The crop window rotates left or right, has no resize control, and opens at about two thirds of the screen height. Save asks for a file when the path is empty. The paper is removed automatically. The button says Open Image. The signature window and the crop window follow the four themes around the paper, and the writing area stays white. The remembered picture is stored in the sumatrapdfcache folder. A picture left in the old place is still read, and the next save moves it in. The stamp button is no longer on the toolbar. It remains in the page context menu.

**Annotations** — While dragging the frame, the circle, square, and other shapes stay with the frame. The center of the resize arrow stays on the frame. In a dark theme, resizing no longer leaves a ghost of the old shape or of the selection frame, and dragging no longer freezes the window or flashes the whole window.

**Crop window** — The size line stays on one line, drawn on the dialog color, with space after Rotate Right.

**Translate** — With no translation API configured, translating a selection opens the browser directly, without flashing the translation window. The translation popup closes when you click outside it. An Ask AI answer is drawn in one step, so the window no longer flashes before it grows.

### 本版更新

**手写签名** — 工具栏和页面菜单都可以写一次，再按住拖动确定大小。放上页面后即可拖动和缩放。点页面空白处退出编辑。单击就能选中，不必按住 Ctrl。按住 Ctrl 再单击仍会打开标注栏。工具栏按钮是羽毛笔。也可以用手机照片：选文件、粘贴，或从微信拖进签名窗口。裁剪窗口可以左转、右转，没有调整尺寸，打开时高度约为屏幕的三分之二。路径空着时，保存会先弹出文件对话框。白纸自动去掉。按钮是「打开图片」。签名窗口和裁剪窗口的外框跟随四套主题，签字区仍是白纸。记住的图片存在 sumatrapdfcache 子目录。以前放在外面的图片仍能读到，下次保存会挪进去。盖章从工具栏拿掉，仍可在页面右键菜单里使用。

**标注** — 拖动外框时，圆、方块等图形跟着外框走。缩放时，双箭头的正中落在外框线上。暗黑主题下调整大小不再留下原来图形或选框的残影，拖动也不再卡住，窗口不再整屏闪。

**裁剪窗口** — 尺寸文字保持一行，直接画在对话框底色上，并和「向右转」拉开距离。

**翻译** — 没有配置翻译接口时，划词翻译直接打开浏览器，不再先闪一下翻译窗口。翻译弹窗点到窗口外面会关掉。Ask AI 的回答一次性画到窗口上，窗口不再先闪一下再变高。

### Upgrade
