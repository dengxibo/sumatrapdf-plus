## What's new

**Extract bookmarks** — Printed-TOC extraction is rebuilt around page geometry: robust page-number calibration, auto-repair of stale official outlines, OCR-glued page numbers filtered out, and order-aware indent levels. Attachments keep their own numbering (`附件 2` with a space still counts), cite-style 附件 lines stay out, and multi-line 函/附件 titles stay one bookmark. Official outline numbers stay consecutive instead of dropping report lines as cover attachments.

**AI TOC import** — Importing a generated TOC shows live progress ("Calibrating bookmark positions… N / M"), verifies each bookmark against the body text, and aborts cleanly when the dialog closes or the import is re-run.

**Paragraph copy** — On by default (`OcrCopyMerged`, OCR menu toggle): copying from OCR results or native-text PDF pages merges soft-wrapped lines into coherent paragraphs, and a long wrapped title copies as a single line so it no longer truncates when pasted as a file name.

**OCR** — Recognition switches to PP-OCRv6 Tiny/Small so RapidOCR v6 IR-10 models load on ONNX Runtime 1.20 without a header patch (current page uses Small, full-document OCR uses Tiny). Auto OCR only turns on by default for image-only scans; Auto-save can overwrite the PDF after a full scan. Landscape scanned forms stand up; vertical books stay upright.

**Rotate pages** — New PDF tools command rotates the current page, all pages, or a specified range; the compact dialog adapts to all four themes.

**Reading position** — Reopening the app reliably restores each tab's saved page and scroll position instead of landing on page 1.

**Find & selection** — The actual hit is highlighted in its own color inside result snippets while other filter words keep the standard highlight, and snippets keep the match inside the visible column. Cross-line CJK selection starts at the anchor (issue #76); selection, search, and word-lookup share one highlight band.

**Read aloud** — Vertical books turn to the next page when the voice leaves the current one, and reading follows OCR-recognized pages instead of skipping them.

**Sidebar** — Dragging the TOC splitter no longer ghosts or flashes; the empty "No bookmarks" text stops flickering; header icons share one gray.

**Toolbar & home** — A stamp tool joins the line tools (click to place, drag to size, Ctrl+click to keep stamping); the fullscreen button moves to the far right. Home restores the list/thumbnails and recent/frequent icon toggles, centers the search field, and fixes list-search flicker and file-name colors.

**Stability** — Fixed a crash after document reload; PDFs that need lenient page-tree recovery are marked as repaired and force a full rewrite when AI TOC or other edits are saved.

## 本版更新

**提取目录** — 印刷目录提取改为以版面几何为主：页码校准更稳、自动修复失准的官方书签、过滤 OCR 粘连页码、按层级顺序定层级。附件编号独立（「附件 2」带空格也算附件2）、函末引用式「附件：…」不再误收、函/附件多行标题收成一条。公文序号保持连续，不再把正文行丢成封面附件。

**AI 目录导入** — 导入生成的目录时显示实时进度（「正在导入目录：校准书签位置… N / M」），逐条和正文核对后再写入；中途关闭或重新导入会安全中止。

**段落复制** — 默认开启（OCR 菜单「段落合并复制」，`OcrCopyMerged`）：从 OCR 结果或原生文字 PDF 复制出来的是连贯段落；折行长标题复制为单行，另存文件名不再被回车截断。

**OCR** — 识别切换到 PP-OCRv6 Tiny/Small，ONNX Runtime 1.20 直接加载 RapidOCR v6 的 IR 10 模型，不再改模型头（当前页用 Small，全文用 Tiny）。只有纯图片扫描 PDF 默认开自动 OCR；新增「自动保存」，识别完全文可覆盖保存 PDF。横向扫描的公文能立起来，竖版书保持正立。

**旋转页面** — PDF 工具新增旋转命令：当前页、全部页或指定范围；紧凑对话框适配四种主题。

**阅读位置** — 重新打开程序能可靠恢复每个标签的页码和滚动位置，不再回到第 1 页。

**查找与选择** — 搜索结果里真正命中的词用独立颜色高亮，其余过滤词保持普通高亮；摘要保证命中词可见。跨行中文选区从起点开始（issue #76）；选择、搜索、取词共用同一条高亮带。

**朗读** — 竖版书读完一栏自动翻到下一页，跟读跟随 OCR 识别出的页面，不再跳过。

**侧栏** — 拖目录分隔条不再出现残影和闪抖；空书签提示不再闪；顶栏图标统一灰色。

**工具栏与首页** — 画线工具后新增图章（单击放置、拖动改大小、Ctrl+点击连续盖）；全屏按钮移到最右侧。首页恢复列表/缩略图、最近/最热两个图标开关，搜索框居中，修复列表搜索闪黑和文件名颜色。

**稳定性** — 修复重载后的崩溃；需要宽容页面树恢复的 PDF 会标记为已修复，保存 AI 目录等编辑时强制完整重写。

便携版升级前请先完全退出程序。
