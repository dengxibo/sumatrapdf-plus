## What's new

**Selection translate and Ask AI** — The selection toolbar has Translate and Ask AI. Translate prefers Volcengine and falls back to the AI API for a translation only. Ask AI answers in the app when an API is configured, and still opens Doubao / DeepSeek / ChatGPT when it is not. The panel can be dragged and resized, copies the translation, sends with Enter, closes with Esc, renders Markdown, and follows Warm, White, Dracula, and Black. The translation and the answer are two points larger than the UI font. The first theme switch after opening Ask AI no longer stalls, and the popup changes color together with the main window. Options splits OCR and AI. The model field is a plain box plus Choose: the list scrolls, a search box filters it, and speech, image, and embedding models are omitted. A name that is not listed can still be typed. Volcengine Secret Key has a Test button.

**Selection** — Copy on the selection toolbar clears the highlight. Closing Lookup, Translate, or Ask AI clears the selection those windows were opened with. A selection made after that stays.

**Multiple screens** — Translate, Ask AI, Lookup, the selection toolbar, the read-aloud bar, the command palette, document properties, tab groups, screenshot, image crop, and the PDF tool windows (bake, extract text, extract or delete pages, compress, decompress, encrypt, decrypt) use the scaling of the screen they are on. Dragging one to another screen updates the text and the window size.

**Dark mode** — High-key photographs such as fog, snow, and white fur keep their tones. Pale cut-out edges (a glass rim, an eggshell, a glass-dish corner, a sweater cuff) stay in their original color. Side-by-side cut-outs on the same row are not clipped against each other. A textbook's full-page cream plate becomes the theme background; body text stays light and colored titles stay as printed.

**Read Aloud** — The bar can be dragged elsewhere on the page until it is closed. Speed opens a menu from 0.25× to 2× for both text-to-speech and narrated books. Follow is translated (Chinese: 跟随). An in-page speaker only starts or restarts playback. PDFs with embedded audio use the same bar. The Read Aloud settings page no longer has separate Chinese, English, and embedded speeds.

**Also** — Changing the EPUB font size stays on the first line of the current window. Continuous zoom (Fit Width, Fit Page, sidebar, resize) keeps the page anchor. Subset Symbol fonts such as `ABCDEF+Symbol` use built-in Base14 Symbol again, so matrix brackets are not plain squares ([#35](https://github.com/dengxibo/sumatrapdf-plus/issues/35)). Scanned pages with no text layer are OCR'd by default when that setting has never been saved. Narrow bookmark titles that do not fit end with an ellipsis. Word lookup drops a trailing period or comma on an English word, and shows one phonetic when the British and American readings match.

## 本版更新

**划词翻译和问问 AI** — 选区工具栏增加「翻译」和「问问 AI」。翻译优先火山；未配置或失败且已配置 AI API 时，只用大模型出译文。已配置 API 时问问 AI 在应用内回答，未配置仍打开豆包 / DeepSeek / ChatGPT。浮层可拖动、右下角调大小、复制译文、回车发送、Esc 关闭，Markdown 按格式显示，四种主题颜色一致。译文和回答比界面字体大 2 磅。第一次打开问问 AI 再切主题不再卡住十几秒，浮层和主窗口一起换色。选项把 OCR 和 AI 拆成两页。模型是普通输入框加「选择」：名单可滚动、可按名称搜索，语音、图片和向量模型不列入；名单里没有的名称仍可直接输入。火山 Secret Key 旁有「测试」按钮。

**选区** — 工具栏点「复制」后高亮消失。关掉查词、翻译或问问 AI 后，打开它们时的那一段选区也会消失。关掉之前已经重新划上的选区会留下来。

**多屏** — 翻译、问问 AI、查词、划词工具栏、朗读条、命令面板、文档属性、标签组、截图、图片裁剪，以及烘焙、提取文本、提取或删除页面、压缩、解压、加密、解密这些窗口，按所在屏幕的缩放显示。拖到另一块屏幕时，文字和窗口大小会跟着变。

**暗色** — 雾、雪、白毛这类高调照片保持连续色调。玻璃杯沿、蛋壳、玻璃盘角、毛衣袖口这类淡色抠图边缘保持原色，不再被切成黑块。同一行并排的抠图不再互相裁切。教材整页奶油色底图换成主题背景，正文仍是浅字，彩色标题保持原色。

**朗读** — 朗读条本次显示期间可以拖到页面上的其他位置，关掉后再打开回到底部居中。倍速改为菜单，系统语音和有声书都是 0.25× 到 2×。「跟随」有中文。页内喇叭只负责开始或重放。带内嵌录音的 PDF 用同一条朗读条。设置里的朗读页不再单独设中文、英语和内嵌速度。

**其他** — EPUB 改字号停在当前阅读窗口第一行。连续模式改缩放保持页面锚点。`ABCDEF+Symbol` 这类子集名重新走内置 Symbol，矩阵外括号不再变成普通方括号（[#35](https://github.com/dengxibo/sumatrapdf-plus/issues/35)）。设置里没有保存过时，没有文字层的扫描页默认自动 OCR。书签栏放不下的标题末尾加省略号。英文选区带句号或逗号时查词仍可用；英美音标相同时只显示一次。

便携版升级前请先完全退出程序。
