# SumatraPDF Plus 3.7.20 (2026-07-31)

**Download:** [SumatraPDF.exe](https://github.com/dengxibo/sumatrapdf-plus/releases/download/3.7.20/SumatraPDF.exe) (portable x64)

Full release page (EN + 中文): [docs/releases/3.7.20.md](https://github.com/dengxibo/sumatrapdf-plus/blob/main/docs/releases/3.7.20.md)

### Highlights

1. **Document color** — one button toggles Match theme / Original (was three buttons).
2. **PDF dark mode** — better display, faster open, more natural Match theme reading.
3. **Background EPUB** — no freeze when returning to a large EPUB tab.
4. **Ultrawide tabs** — fix small tab bar font on high-DPI ultrawide screens.
5. **Selection** — fix LTR drag where two characters often became three.
6. **Read aloud** — no double-click to start; double-click pauses/resumes while reading.

### 本版更新

1. **文档颜色** — 一个按钮在 **跟随主题 / 原稿** 之间切换（原先三个按钮）。
2. **PDF 暗黑模式** — 显示与打开更好，跟随主题更自然。
3. **后台大 EPUB** — 从其他标签切回大 EPUB 不再卡死。
4. **带鱼屏标签页** — 修复标签栏字体过小。
5. **划词** — 修复从左向右拖两字容易变成三字。
6. **朗读** — 双击不再开始朗读；朗读中双击暂停/继续。
