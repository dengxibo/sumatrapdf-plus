## Highlights / 本版更新

1. **Document color** — one toolbar button toggles **Match theme / Original** (was three buttons).  
   **文档颜色** — 工具栏改为一个按钮，在 **跟随主题 / 原稿** 之间切换（原先为三个按钮）。

2. **PDF in dark mode** — better display and faster open; Match theme reads more naturally.  
   **PDF 暗黑模式** — 显示与打开体验更好，跟随主题时阅读更自然。

3. **Background EPUB tabs** — switching back to a large EPUB tab no longer freezes the app.  
   **后台大 EPUB** — 大 EPUB 在后台标签时，从其他标签切回来不再长时间无响应。

4. **Ultrawide tab bar** — tab labels scale correctly on high-DPI ultrawide monitors.  
   **带鱼屏标签页** — 修复超宽高分屏上标签栏字体过小的问题。

5. **Text selection** — fixed left-to-right drag where selecting two characters often included a third.  
   **划词选区** — 修复从左向右拖两个字时很容易多带上第三个字的问题；其他拖选长度不受影响。

6. **Read aloud & double-click** — double-click no longer starts read aloud; while reading, double-click pauses and double-click again resumes.  
   **朗读与双击** — 不再支持双击开始朗读；朗读中双击暂停，再双击从暂停处继续。
