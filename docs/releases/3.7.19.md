## Highlights / 本版要点

1. **Math & vector notation** — correct rendering of operators and matrix brackets in many textbook PDFs.  
   **向量与公式符号** — 修复教材 PDF 中运算符、矩阵括号等显示错乱。

2. **Text selection** — smoother CJK and EPUB selection, formula highlights (accents, subscripts), toolbar behavior.  
   **划词选区** — 改进中文/EPUB 拖动选词、公式高亮（含上标/下标/波浪号等）及选区工具栏。

3. **PDF links** — external and in-document links work without waiting for full page parse.  
   **PDF 链接** — 参考文献 DOI 等外链无需等整页解析完成即可识别并跳转。

4. **Theme & document color** — faster, more stable switches; less blank reflow after first theme/color change on EPUB.  
   **主题与色彩模式** — 切换更快、更稳；可重排 EPUB 首次切换后空白问题减轻。

## 1. Math & vector operator display / 向量运算与公式符号显示

**English**

- Fixed wrong glyphs for **vector/matrix notation** in some textbook PDFs (e.g. square brackets instead of scalable matrix fences).
- Embedded **Symbol** font subsets (names like `YFLGZT+Symbol`) now map to the correct built-in Symbol faces so operators and brackets match the author’s intent.
- Improves readability of linear-algebra and statistics formulas that use special bracket and operator fonts.

**中文**

- 修复部分**教材 PDF** 中向量、矩阵符号显示错误（例如矩阵外括号变成方括号、运算符字形不对）。
- 对 `YFLGZT+Symbol` 等 **Symbol 子集** 使用正确的内置 Symbol 字形，矩阵可伸缩括号与运算符显示与原版一致。
- 线性代数、概率统计等含特殊括号/运算符的公式阅读体验明显改善。

---

## 2. Text selection / 划词选区

**English**

- **CJK & EPUB:** drag selection respects reading direction (LTR/RTL), reduces jitter, accidental cross-line ranges, and stale selection when starting a new drag.
- **Formulas:** selection can span `arg max`, accents (e.g. tilde over *Q*), and subscripts; highlight bands use true glyph bounds and merge split math runs where appropriate.
- **UI:** clicking empty space dismisses the selection toolbar; layout changes (theme reflow) re-sync selection more reliably.

**中文**

- **中文与 EPUB：** 从左/从右拖动更符合习惯，减少抖动、误跨行、重新划词时沿用旧选区等问题。
- **公式：** 可选中 `arg max`、上标/下标及 Q̃ 等变音符号；高亮按字形外框绘制，并合并被零宽字形拆开的公式片段。
- **界面：** 点击空白处关闭划词工具栏；主题重排后选区恢复更稳定。

---

## 3. PDF link navigation / PDF 链接跳转

**English**

- **URI links** (DOI, `https://…` on reference pages) show a hand cursor and open correctly even when the page is only **partially rendered**.
- Link annotations are loaded on **hover**, same approach as EPUB, instead of requiring a full parse pass first.
- Fixes “link looks dead until I scroll or wait” on large or slow PDFs.

**中文**

- **URI 外链**（参考文献页 DOI、`https://…`）在页面尚未完全解析时即可显示手型光标并正常打开。
- 悬停时加载链接注释（与 EPUB 一致），不必等整页解析结束。
- 解决大文件或慢盘上“要等很久链接才能点”的问题。

---

## 4. Theme & document color mode / 主题与色彩模式

**English**

- **Reflow EPUB/MOBI:** theme or **document color mode** (Smart / Original / Match theme) triggers re-pagination only after the **canvas viewport** is valid, avoiding huge blank gaps on the first switch.
- **Match theme** on reflow documents can recolor the **page bitmap** (including figures), not only CSS text/background.
- **Progress feedback:** wait cursor and chapter progress when a full book re-layout runs; duplicate relayout requests on the same document are ignored.
- Renamed advanced setting to **`DocumentColorMode`** (`smart` / `original` / `theme`) with automatic migration from older names.

**中文**

- **可重排 EPUB/MOBI：** 切换主题或**文档颜色模式**（智能 / 原稿 / 匹配主题）时，在**画布视口就绪**后再重排版，减轻首次切换后出现大段空白。
- **匹配主题** 时对整页位图（含插图）做主题着色，不仅改 CSS 文字/背景。
- **进度提示：** 全书重算分页时显示等待光标与章节进度；同一文档重复触发重算会被忽略。
- 高级设置统一为 **`DocumentColorMode`**（`smart` / `original` / `theme`），旧配置名自动迁移。
