# SumatraPDF Plus 3.7.85

## 中文

- 截图及图片编辑窗口在“保存”旁新增“复制”按钮，可将当前裁剪或缩放结果直接粘贴到 Word、笔记和聊天中。
- 复制成功显示“已复制”，窗口保持打开；保留 Ctrl+C 快捷键。

下载 Windows x64 EXE。退出程序后替换安装目录中的 EXE，保留配置及配套文件。

## English

- Add a Copy button beside Save in the screenshot and image editor to copy the current crop or resize result to the clipboard.
- Show confirmation after copying and keep the editor open. Ctrl+C remains available.

Download the Windows x64 EXE. Close the application before replacing the EXE; retain settings and supporting files.
