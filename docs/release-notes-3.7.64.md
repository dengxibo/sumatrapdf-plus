# SumatraPDF Plus 3.7.64

## 中文

- 改善图片裁切框移动和调整大小时的响应，减少拖动过程中的重复控件布局和无效图片重绘。
- 松开鼠标时按最终位置更新选框，避免遗漏最后一次移动。

[下载 Windows x64 EXE](https://github.com/dengxibo/sumatrapdf-plus/releases/download/3.7.64/SumatraPDF-Plus.exe)。退出程序后替换完整安装目录中的 EXE，保留配置及配套文件。

## English

- Improve image crop selection movement and resizing by avoiding repeated control layout during dragging and unnecessary image repaints when only the size label changes.
- Apply the final mouse position when releasing a drag.
