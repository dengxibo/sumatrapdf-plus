# AI 目录识别（API）

在“设置 → OCR 与 AI → AI 目录识别（API）”中管理平台配置：

1. 用“添加”建立一套平台配置，填写名称、OpenAI 兼容的 Base URL 和 API Key。
2. 点击“获取模型”读取该平台的 `GET /models` 列表。直接在“模型”框输入关键词，匹配结果会随输入自动展开；从下拉列表中选择完整模型 ID。部分平台不提供 `/models` 接口，此时仍可在同一框中手工填写模型 ID。
3. 将并发数设为 1–8。管控严格的平台可从 1 开始，默认值为 4。此限制应用于目录页检测、逐页识别和页码偏移采样的并行请求。
4. 点击“测试”检查当前地址、密钥和模型；点击设置窗口的“确定”保存全部平台配置和当前选中的平台。

切换平台时，当前输入会先保存在设置窗口中；点击“取消”会放弃本次所有修改。升级旧版后，原来的单套 API 设置会成为“Default”配置。现有 `autoContents` 配置文件只在 Sumatra PDF Plus 尚无完整 API 配置时用来预填，不会修改 `autoContents` 的文件或工作流程。

打开 PDF 后，使用“视图 → AI 提取目录书签”。在候选目录页确认界面选好页面，然后点“API 识别”（OpenAI 兼容接口）或“网页 AI 识别”（剪贴板发给网页版 AI）；若本地无法找到目录页，可在回退界面点“AI 检测目录页”。生成结果进入目录校准界面，确认后写入 PDF 书签。

API Key 写入 `SumatraPDF-settings.txt` 时使用 Windows DPAPI（`CryptProtectData`）按当前用户加密，设置文件里呈 `dpapi:` 前缀；运行中解密后使用。换用户或换机无法解密，需重新填写。旧版明文 Key 会在下次保存时自动加密。

如果 API 处理较慢，可在 `%TEMP%\SumatraPDF-Plus\AI-TOC\api-*` 的本次运行目录查看 `*.meta.txt`：`elapsed_ms` 是该请求连同重试的总耗时，`attempts` 是尝试次数，`success` 表示该步骤是否成功。检测目录页、提取逐页标题和判定层级分别记录，便于区分平台响应慢与重试造成的等待。


所有平台的 API 请求默认携带 `enable_thinking: false`，尽量跳过模型的思考阶段。若平台明确拒绝该字段，应用会自动重试一次并缓存该平台与模型的兼容结果。平台是否执行该参数及实际加速幅度取决于服务商和模型。
