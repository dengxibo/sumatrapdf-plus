# SumatraPDF Plus 3.7.54

## 中文

- 目录校准的半边右箭头统一使用原来无偏移值时的长度，不再随偏移文字宽度变化。
- 有无偏移值均保持相同的箭头长度和靠下位置。

[下载 Windows x64 EXE](https://github.com/dengxibo/sumatrapdf-plus/releases/download/3.7.54/SumatraPDF-Plus.exe)。退出程序后替换完整安装目录中的 EXE，保留配置、字典、OCR 模型及配套文件。

语音适配器附件沿用上一版：[替换说明、许可证及对应源码](https://github.com/dengxibo/sumatrapdf-plus/blob/3.7.50/docs/release-notes-3.7.50.md)。这些附件为可选组件，不要放入 SumatraPDF 安装目录。

构建及已有单元测试通过；最新布局尚未完成完整人工验收。

## English

- Use the previous no-offset length for all TOC calibration half-arrows instead of matching offset text width.
- Keep the same arrow length and lower alignment with or without an offset value.

[Download Windows x64 EXE](https://github.com/dengxibo/sumatrapdf-plus/releases/download/3.7.54/SumatraPDF-Plus.exe). Close the application before replacing the EXE in an existing complete installation; retain settings and supporting files.

Optional speech adapter assets are unchanged; see [instructions, licenses and source links](https://github.com/dengxibo/sumatrapdf-plus/blob/3.7.50/docs/release-notes-3.7.50.md).

Build and existing unit tests passed; full interactive layout verification remains pending.
