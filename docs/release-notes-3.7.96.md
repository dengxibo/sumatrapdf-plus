# SumatraPDF Plus 3.7.96

## 中文

- 主页竖版封面可通过 Ctrl + 滚轮放大到与横版缩略图相同的宽度上限（#125）。
- 修复部分 EPUB 的 SVG 封面裁切问题，封面现在按原比例完整显示。
- EPUB 正文中的提示框会按原书指定的圆角显示。

下载 Windows x64 EXE。退出程序后替换安装目录中的 EXE，保留配置及配套文件。

## English

- Use Ctrl + mouse wheel to enlarge portrait covers on the Home page up to the same width as landscape thumbnails (#125).
- Fix clipping on some SVG covers in EPUB books so the full cover fits at its original aspect ratio.
- Render rounded corners on EPUB callout boxes when specified by the book.

Download the Windows x64 EXE. Close the application before replacing the EXE and retain settings and supporting files.
