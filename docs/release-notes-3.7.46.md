# SumatraPDF Plus 3.7.46

## 中文

本版修复选项对话框下拉框在鼠标悬停时的抖动和闪烁。

- **下拉框悬停：** 选项对话框各页的下拉框在鼠标移入/移出时不再整控件抖动；浅色主题不再因悬停边框变化闪一下。
- **展开列表：** 展开后的列表用双缓冲绘制，换行选中时只重画变化的行。
- **设置滚动：** 键盘/焦点移动时按布局矩形滚动到可见区域，避免按错误窗口高度滚动。

## English

This release fixes Options dialog combo boxes that shook or flashed on hover.

- **Closed face hover:** combo boxes on Options tabs no longer shake on mouse enter/leave; light themes keep a stable closed face without a hover border flash.
- **Dropped list:** the open list paints with double buffering and invalidates only the rows that change when the selection moves.
- **Settings scroll:** focus scroll-into-view uses the layout rectangle so the page does not jump from the wrong window height.
