# AI 侧栏与配置优化（2026-10-15）

## 实现

- `src/InlineTranslate.cpp/.h`：对话区和输入框复用 TOC 原生滚动条主题；独立的复制、全选、复制整条回复菜单；新对话确认、取消请求、清空历史和回调代次隔离。API 配置与临时模型跟随当前文档对话，切换文档时一并停放/恢复，不写入全局默认设置。
- `src/MainWindow.cpp/.h`：提取 `SyncSidebarScrollbarTheme`，供 TOC 和 AI 控件共用。主题切换刷新非客户区缓存。全局 DarkMode 处理会给 RichEdit 添加边框，AI 侧栏在该处理之后恢复无边框样式，再布局和重绘，避免依赖覆盖绘制遮挡亮边。
- `src/AiTocApi.cpp/.h`：提取并复用 API 档案解析；根据接口能力信息过滤模型，通用选择器优先显示视觉模型。未知模型继续可选；名称规则只作为缺少能力信息时的保守补充。视觉测试发送生成的六位数字图片并核对回答，与普通文本测试明确区分。请求取消对象管理 WinINet 句柄及跨线程生命周期。
- `src/SumatraDialogs.cpp/.h`、`src/SumatraPDF.rc`、`src/resource.h`：智能页增加默认对话 API、默认对话模型及合并的文本/视觉测试，复用现有带搜索的模型弹窗；API 变更时清除旧的对话模型覆盖，删除配置时调整索引或回退通用 API。新增控件参与现有页面滚动、标签对齐和宽度调整。
- `cmd/gen-settings.ts`、生成的 `src/Settings.h`、`docs/md/Advanced-options-settings.md`：持久化 `AiChatApiProfile`（-1 为继承通用 API）和 `AiChatModel`（空为继承对应 API 模型）。旧字段及密钥存储格式保持兼容。
- `src/SumatraPDF.cpp`：保存选项后刷新当前及停放的对话配置，不清空消息。
- `translations/translations-good.txt`、`translations/translations.txt`：补充简体/繁体中文界面文案，已重新打包翻译资源。

模型菜单保持紧凑：显示当前模型的选中标记，通过已有搜索弹窗选择模型，API 统一在智能设置页选择；“AI 配置…”固定在根菜单底部，与上方项目用分隔线隔开。
