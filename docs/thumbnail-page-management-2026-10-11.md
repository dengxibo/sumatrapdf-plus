# 缩略图页面管理（两批交付）

## 第一批

- PDF 缩略图支持 Ctrl 多选、Shift 连选、Ctrl+A 全选（全选当前筛选显示的页）。
- 右键菜单支持复制、剪切、粘贴到当前页之前/之后、删除、撤销；缩略图获得焦点时对应 Ctrl+C/X/V、Delete、Ctrl+Z。
- 拖动多选页进行排序，按原文档顺序移动，显示竖向插入线；支持靠近上下边缘滚动。筛选期间禁止拖动重排，避免隐藏页造成歧义。
- 删除显示选中页数并默认选“否”；不允许删除或剪切全部页面。剪切成功写入剪贴板后才执行删除确认。
- 页面剪贴板是专用格式中的独立 PDF，不依赖源文件/标签继续打开；可在其他 PDF 标签内粘贴，保持矢量内容及普通批注。复制页的批注、Contents 数组彼此独立。
- 页面排序历史保留最多 32 次，撤销恢复页面引用及顺序，不用整个 PDF 快照覆盖后来对保留页面进行的批注编辑。保存重载后历史清空；撤销后保守保留未保存标记。

## 第二批

- 从未加密 PDF 或图片文件在当前页之前/之后插入。图片支持 MuPDF 可读取的 PNG/JPEG/BMP/TIFF/WebP 等，按图片分辨率建立一页。多帧图片目前仅插入首帧。
- 从 Windows 剪贴板 DIB/DIBV5 图片插入一页，使用内存 BMP 转 PDF，无中间落盘文件。
- 提取选中页面至用户指定的新 PDF，按原页面顺序输出。禁止覆盖当前源文件。提取只创建输出文件，不改变当前文档。

## 数据与主题

修改当前文档的操作都只改内存，引擎标记 PDF 未保存，刷新标签红点及保存入口。手工保存才写入当前文档，关闭可放弃。右键菜单复用应用 owner-draw 主题，选择框复用主题色，不另建配色。

后台执行 PDF 复制/结构修改/导出，期间禁用当前窗口编辑；等待现有缩略图渲染结束再开始，取消主页面渲染，完成后重建引擎页缓存、显示模型页尺寸/搜索与选择状态、目录、缩略图及页码。缩略图任务携带代次，拒绝旧位图。

识别正在进行时暂不接受编辑；有未保存 OCR 文字时，先保存识别结果后再重排/插入/提取，防止纯页码 OCR 缓存对应错页。普通复制可用。页面复制保留外部 URI 链接，跨文档的内部跳页链接与复杂交互式表单关系不在本次支持范围内。

## 验证

`tests/PdfPageEditingTests.cpp` 使用真实 MuPDF 文档测试：1–8 页所有多选集合及插入边界、非连续选择顺序、删除/恢复、继承页面尺寸、批注副本互不影响、保存后重开和图片插入后的实际像素渲染。

应用程序构建及底层测试完成；四主题下右键菜单、连续操作、跨标签粘贴及关闭/保存流程需用户界面验证。
