# SumatraPDF Plus 3.7.98

## 中文

- 双击插图或从右键菜单选择「图片 → 查看大图」，在阅读区打开预览。支持滚轮缩放、拖动、左右翻图，以及双击或 Esc 返回原阅读位置。适用于 EPUB、PDF、DOCX、MOBI、AZW 和 AZW3 中可识别的独立图片。
- EPUB 插图说明单行仍居中，多行改为整块居中、文字左对齐。
- 改善 DOCX 公文的红头、横线、版记和名单排版，隐藏多余的「文号」模板书签标题。

下载 Windows x64 EXE。退出程序后替换安装目录中的 EXE，保留配置及配套文件。

## English

- Preview illustrations in the reading area by double-clicking or choosing Image → View Image. Zoom with the wheel, drag the image, browse with the arrow keys or buttons, and double-click or press Esc to return. Works with recognized images in EPUB, PDF, DOCX, MOBI, AZW, and AZW3.
- Keep one-line EPUB captions centered and left-align the text of longer captions within a centered block.
- Improve DOCX letterheads, rules, imprint lines, and attendance lists, and suppress the extra heading generated from the 文号 template bookmark.

Download the Windows x64 EXE. Close the application before replacing the EXE and retain settings and supporting files.
