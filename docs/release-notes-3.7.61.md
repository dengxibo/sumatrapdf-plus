# SumatraPDF Plus 3.7.61

## 中文

- PDF、图片页面支持 **Alt+Shift+左键拖动**框选保存，无需 OCR；支持反向拖动，选区限制在起始页面。Esc 取消。
- 裁剪窗口支持拖动重画选区、八个控制点调整大小、空格加拖动移动选区。
- 新增“保存后打开图片”（默认关闭并记住选择）；保存成功后关闭编辑窗口，记住最近成功保存的文件夹，建议文件名自动避让重名。
- 图片编辑界面适配 Warm、White、Dracula、Dark 四种主题和 DPI 变化；增加简繁中文、德文及阿拉伯文提示，改进长文案布局。

[下载 Windows x64 EXE](https://github.com/dengxibo/sumatrapdf-plus/releases/download/3.7.61/SumatraPDF-Plus.exe)。退出程序后替换完整安装目录中的 EXE，保留配置及配套文件。

## English

- Hold **Alt+Shift** and drag on PDF or image pages to export a region without OCR. Selection stays on the starting page; Esc cancels.
- Redraw a crop selection by dragging, resize with eight handles, or hold Space and drag to move it.
- Remember the last successful export folder and the optional “Open image after saving” choice (off by default). Successful saves close the editor; suggested names avoid existing files.
- Adapt the image editor to four themes, DPI changes, longer translations and RTL action layout.

[Download Windows x64 EXE](https://github.com/dengxibo/sumatrapdf-plus/releases/download/3.7.61/SumatraPDF-Plus.exe). Close the application before replacing the EXE in an existing complete installation; retain settings and supporting files.
