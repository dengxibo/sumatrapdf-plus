# SumatraPDF Plus 3.7.97

## 中文

- 修复 DOCX 中 `Content` 书签名显示为正文标题和侧栏条目的问题。
- 修复部分 DOCX 中单个汉字缺少东亚字体设置时误用段落字体的问题。

下载 Windows x64 EXE。退出程序后替换安装目录中的 EXE，保留配置及配套文件。

## English

- Keep DOCX bookmarks named `Content` as navigation targets without displaying their name as a heading or an outline entry.
- Fix incorrect fonts for Chinese characters in DOCX runs that omit the East Asian font setting.

Download the Windows x64 EXE. Close the application before replacing the EXE and retain settings and supporting files.
