# SumatraPDF Plus 3.7.81

## 中文

- PDF 页面转图片新增快捷键 **Ctrl+Shift+E**，打开导出对话框。
- 新增“导出成功后打开文件夹”选项，默认勾选并记住选择。全部页面导出成功后打开本次输出子目录；取消或失败时不自动打开。

[下载 Windows x64 EXE](https://github.com/dengxibo/sumatrapdf-plus/releases/download/3.7.81/SumatraPDF-Plus.exe)。退出程序后替换完整安装目录中的 EXE，保留配置及配套文件，重启后生效。

## English

- Add **Ctrl+Shift+E** to open the PDF page image export dialog.
- Add “Open folder after successful export”, enabled by default with your choice remembered. The output subfolder opens after all pages finish successfully; cancellation or failure does not open it.

[Download Windows x64 EXE](https://github.com/dengxibo/sumatrapdf-plus/releases/download/3.7.81/SumatraPDF-Plus.exe). Close the application before replacing the EXE; retain settings and supporting files, then restart.
