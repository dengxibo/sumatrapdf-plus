# SumatraPDF Plus 3.7.62

## 中文

- 工具栏保持单行，空间不足的按钮按功能收入“更多工具”；放大窗口后自动恢复，优先保留页码、翻页和搜索。
- 收纳菜单保留工具的选中、禁用状态，以及朗读、识别选项；支持键盘操作、四主题、多语言和 DPI 变化。中文 OCR 分类显示为“识别”。
- Alt+Shift+左键拖动框选保存扩展至所有支持分页渲染的文档，包括 Word、电子书、漫画等。
- 图片保存按钮移至底部右侧；旧电子书引擎导出使用文档原始配色。

## English

- Keep the toolbar on one row and move tools into grouped overflow menus as space shrinks. Restore them when widened, with page navigation and search taking priority.
- Preserve checked and disabled states, reading and OCR options, keyboard operation, themes, translations and DPI handling.
- Extend Alt+Shift region image export to all paginated document formats, including Word, ebooks and comics.
- Place Save at the bottom right of the image editor and retain original document colors when exporting from the legacy ebook engine.
