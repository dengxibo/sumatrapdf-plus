# SumatraPDF Plus 3.7.117

- EPUB 工具栏新增「排版」菜单，可为当前书调整段间距、行距、首行缩进和正文对齐，也可将任一设置设为默认值。
- 修复暗色主题下 EPUB 彩色文字变成灰白的问题。对比度不足的彩色文字会适当提亮。
- AI 侧栏支持框选页面、粘贴剪贴板图片，以及从阅读区或资源管理器拖入图片。每条消息最多附四张图片，发送后会在对应提问下显示缩略图。发送图片需要支持图片输入的模型。
- 包含 3.7.116 预发布版的 EPUB 改进。可让新 EPUB 遵循全局默认布局，切换单页和双页时继续朗读并重新对齐高亮。

新用户可先下载 [3.7.107 完整包](https://github.com/dengxibo/sumatrapdf-plus/releases/tag/3.7.107)，再替换 EXE。

English: Adds EPUB paragraph controls, preserves colored EPUB text in dark themes, and adds AI chat image attachments and thumbnails. Includes the EPUB layout and read-aloud changes from 3.7.116.
