# SumatraPDF Plus 3.7.109

## 下载与更新

**完整包在 [3.7.107 发布页](https://github.com/dengxibo/sumatrapdf-plus/releases/tag/3.7.107)。新用户请先下载完整包并解压，再用本版 `SumatraPDF-Plus.exe` 替换其中的同名文件，更新到 3.7.109。**

- 完整程序包：`Sumatra.PDF.Plus.MainProgram.zip`。
- 需要词典的用户可选择：`Sumatra.PDF.Plus.MainProgram+dictionary.zip`。
- 已有完整程序目录的用户：退出程序后替换 EXE，保留原有设置、OCR 模型、词典和其他配套资源。本版仅提供 EXE 更新文件。

## 本版改进

- 修复“保存图像”窗口中 PNG 等格式下拉框比旁边按钮矮的问题。
- 统一格式下拉框、旋转、裁剪、调整大小等操作按钮的可见高度，并协调路径栏、浏览按钮和底部复制、保存按钮的尺寸及间距。
- 保持不同 DPI 缩放和窄窗口换行时的对齐；通过四种主题、五种语言及多种 DPI 的 55 项回归检查。

## English

The complete packages are available in [3.7.107](https://github.com/dengxibo/sumatrapdf-plus/releases/tag/3.7.107). New users should download and extract a complete package first, then replace its `SumatraPDF-Plus.exe` with this release's executable to update to 3.7.109. Existing users can replace only the EXE after closing the app, keeping settings and supporting resources.

- Match the visible height of the PNG/format selector to the image action buttons.
- Coordinate the path field, Browse button, action row and Copy/Save buttons, including DPI scaling and wrapping in narrow windows.
- Pass 55 regression checks covering four themes, five languages and multiple DPI settings.
