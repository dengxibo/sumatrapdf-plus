# SumatraPDF Plus 3.7.119

**新用户可以先下载并解压 [3.7.117 完整包](https://github.com/dengxibo/sumatrapdf-plus/releases/tag/3.7.117)，再用本版的 `SumatraPDF-Plus.exe` 替换包内同名文件。** 已有完整包的用户退出程序后直接替换 EXE 即可。

- 缩略图侧栏新增可拖动的滚动条，适配四种主题。调整侧栏宽度时，目录和缩略图会实时跟随鼠标，滚动条暂时隐藏，松手后恢复。修正了标题按钮和右侧分隔线在拖动时的重绘问题。（#135）
- AI 识别目录已解除每个任务最多选择 20 页的限制。网页 AI 仍按每批最多 10 张图发送，API 模式逐页请求并自动合并结果。（#136）
