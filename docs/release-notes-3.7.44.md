# SumatraPDF Plus 3.7.44

## 中文

本次版本专注于改善 AI 对话的阅读体验。

- **边输出边看：** AI 回复改为流式显示，收到内容后就逐步呈现，无需等待整段回复生成完毕。
- **从开头阅读：** 新一轮对话从最新问题附近开始显示，长回复不再自动跳到末尾。
- **保持阅读位置：** 生成新内容和回复完成时保留当前阅读位置，方便按自己的速度阅读和滚动。

## English

This release focuses on a smoother AI chat reading experience.

- **Read as replies arrive:** stream AI reply content instead of waiting for the entire answer to finish.
- **Read from the beginning:** start each turn near the latest question without jumping to the end of a long answer.
- **Keep your place:** preserve the reading position as new content arrives and when the reply finishes.

[Download Windows x64 Release EXE](https://github.com/dengxibo/sumatrapdf-plus/releases/download/3.7.44/SumatraPDF-Plus.exe)

Close the app before replacing the EXE in an existing complete installation. Keep settings, dictionary, OCR and supporting files. The EXE is provided first; the maintainer will upload a ZIP separately.

Streaming requires support from the selected AI API service. Time to the first content still depends on the service.
