# SumatraPDF Plus 3.7.43

## 中文

- 手动调整页面支持裁切比例锁定、批量逐页预览和本页单独调整；统一框使用 PDF 实际尺寸保存，并在应用前检查越界。
- 页面调整先写入内存，显示未保存红点，由用户保存或放弃；修复应用时窗口未响应及调整后的保存问题。
- 缩略图侧栏支持多选、删除、复制、剪切、粘贴、拖动排序和撤销；支持插入 PDF、图片与剪贴板图片，以及提取选中页。
- 统一提示框、输入框和按钮的主题风格，修正提示框标题与标准按钮的语言；按钮按 DPI 与文本尺寸布局。
- 改善调整窗口的滚动、参考网格、翻页控件、透明缩放按钮、旋转按钮及语言选择框；标签关闭按钮改为小型中性叉号和淡色悬停圆底。
