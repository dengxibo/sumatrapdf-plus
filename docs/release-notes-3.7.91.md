# SumatraPDF Plus 3.7.91

## 中文

- 修复 EPUB 标题字号和粗体被阅读器样式覆盖：保留原书标题、强调文字、粗体段落和表头的字重。
- 调整 EPUB 阅读字号时保留标题和注释的相对大小，不再将标题、正文和小字强制设为同一字号（#121）。

下载 Windows x64 EXE。退出程序后替换安装目录中的 EXE，保留配置及配套文件。

## English

- Preserve publisher font weights for EPUB headings, emphasized text, bold paragraphs, and table headers instead of overriding them with reader styles.
- Preserve relative heading and note sizes when adjusting the EPUB reading font size, instead of forcing all text to the same size (#121).

Download the Windows x64 EXE. Close the application before replacing the EXE; retain settings and supporting files.
