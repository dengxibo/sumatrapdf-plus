# 手动调整页面：FastStone 参考优化

- 明亮主题预览画布使用中灰色（RGB 170,170,170），与纸面明确分离；护眼主题保留色调并加深。
- 倾斜角度控件为滑条 + 小数输入框 + 原生上下微调按钮，步长 0.05°。移除 −5° / 0° / +5° 标注及独立加减按钮，不添加清除按钮。
- 手动裁切默认关闭，与自动裁切互斥。开启后拖框选择保留区域；拖动八个边角手柄改变大小，拖动选区内部移动；选区外可重新框选。关闭手动裁切恢复整页预览，保留选区便于再次开启。
- 选区使用旋转、镜像之后的页面包围框的相对坐标。缩放和拖动不改变选区内容；批量应用按同一相对坐标裁切各页。
- 只有点击应用才修改 PDF，取消不写入。保存沿用页面内容流矩阵变换，不将页面栅格化；裁切会改变页面可见范围。
- 预览和保存共用 PdfAdjustmentManualCrop 换算，验证非法/越界输入、原点偏移、像素与 PDF 点坐标比例一致性；现有 17,980 个旋转裁切几何案例通过。

人工验收：明亮/暗黑/护眼主题；普通/最大化/高 DPI；滑条、键盘和上下微调；手动框选、八方向缩放、移动、关闭再开启；旋转镜像后裁切；缩放后选区；不同尺寸页面批量保存并重开。依照用户约定，界面及 PDF 保存验收由用户进行。


## 批量裁切与比例锁定（2026-10-11）

- 手动裁切新增自由、锁定当前框、原页、A4 横竖、1:1、4:3、3:4 比例；选择后以框中心调整并适配页边。八个锚点支持等比缩放。
- 统一框以最终变换后页面左上角为原点，按实际 PDF 单位保存。翻页不缩放裁切框；尺寸不符显示越界提示。
- 勾选“本页单独调整”复制统一框，修改仅影响该页；取消勾选恢复统一框。例外在窗口内保留，只应用所选范围内的记录。
- 预览下方上一页/下一页仅遍历应用范围；页码输入按 Enter 或移出焦点提交。原始“当前页”范围不随预览翻页改变。
- 点击应用先检查全部目标页，越界时列出页码且不开始修改。加载失败清除旧预览。取消不应用临时框。
- 自动验证：比例、八锚点、四方向新建、边界、移动尺寸不变、统一框与逐页例外、不同页尺寸映射、角度/镜像输出尺寸；界面交由用户验证四主题、窄窗/最大化、翻页与真实 PDF 保存。

- 逐页调整连续操作：勾选“本页单独调整”后，上一页/下一页和页码跳转会继续进入单独调整。已有例外保持不变，新页复制统一框；取消勾选仅恢复当前页，保留其他页的调整。

## 应用后保留未保存修改

手动调整窗口点击“应用”只更新当前 PDF 引擎中的页面，不调用保存、文件替换或磁盘重载。清理旧渲染缓存、重新计算页面尺寸并保留主窗口浏览位置。接入既有 PDF 未保存状态，刷新标签页红点及保存命令；用户手工保存才写入文件，关闭时可保存、放弃或取消。关闭调整窗口前点击取消不会执行调整。

验证：构建通过（0 警告、0 错误）。待用户界面验证：应用后文件时间与内容不变，标签红点出现；关闭选择放弃后重新打开恢复原文件；手工保存后重开保留裁切/旋转/倾斜。
