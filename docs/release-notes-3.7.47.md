# SumatraPDF Plus 3.7.47

## 中文

本版补齐选项对话框里可输入下拉框的箭头和浅色输入框圆角，并让明亮模式下被小块白底盖住的图片重新显示。

- **下拉箭头：** 树字体、默认缩放、西文字体、中日韩字体的向下箭头与其他下拉框一样完整显示。这四个框可以打字，里面的输入区不再盖住箭头。
- **圆角输入框：** 浅色主题下的单行输入框改为与下拉框一致的圆角矩形。
- **设置滚动：** 滚轮滚到页面尽头时不再整页抖动。
- **明亮模式图片：** 盖在嵌入图片上的小块近白矢量底不再挡住图片内容（例如表格截图里的蓝色小标志）。大块说明底和页面底色仍会保留。
- **识别：** 自动识别只预读下一页，不再把前后多页排成整份识别。识别菜单增加「识别当前页」。
- **深色对话框：** 边框改用与选项分组相同的淡色描边，贴在深色主窗口上仍能看出轮廓。

## English

This release completes the Options dropdown arrow and rounded light-theme fields, and shows images that a small white plate had covered in light mode.

- **Dropdown arrow:** Tree font, default zoom, and the Latin / CJK font boxes show the same full down arrow as the other dropdowns. Their typing field no longer covers the arrow.
- **Rounded fields:** single-line inputs in light themes use the same rounded rectangle as the dropdowns.
- **Settings scroll:** reaching the end with the wheel no longer shakes the page.
- **Light-mode images:** a small near-white vector plate painted on top of an embedded image no longer hides that picture (for example a blue logo inside a spreadsheet screenshot). Large caption cards and the page background are kept.
- **OCR:** Auto OCR prefetches only the next page. The OCR menu can recognize the current page.
- **Dark dialogs:** the border uses the same muted edge as Options groups, so a dialog still has a silhouette on a dark main window.
