# SumatraPDF Plus 3.7.123

已有完整包的用户可退出程序，替换同名 EXE。新用户可先下载 [3.7.117 完整包](https://github.com/dengxibo/sumatrapdf-plus/releases/tag/3.7.117)，再替换 EXE。

- 修复单页和非连续双页模式下 Ctrl＋滚轮缩放未围绕鼠标位置的问题（#137）。右键＋滚轮也使用相同的鼠标锚点处理。
- 改进英文 PDF 的「合并段落复制」：识别完整单词换行留下的参差行尾，减少将同一段拆开的情况，继续保留明显的首行缩进、段间距和列表边界。
- 修复 EPUB 缺少源段落标记、需要参考版面时，首行缩进后回到正文左边界可能导致段内复制断开的问题。源段落和明确换行仍优先保留。

PDF 段落合并仍需根据版面推断，复杂教材的公式、多栏和特殊排版可能需要进一步调整。本次针对英文参差行尾、EPUB 缩进及段落边界增加了回归检查；论坛反馈所用的原文件尚未提供，仍欢迎提供复现样本。
