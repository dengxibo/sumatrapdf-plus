# SumatraPDF Plus 3.7.71

## 中文

- 标签拖离标签栏后立即分离为完整窗口，继续跟随鼠标移动，松手后停在落点。
- 按鼠标所在屏幕定位分离窗口，改善双屏拖动，并按屏幕缩放比例调整标签抓取位置。
- 保留标签栏内排序，支持将分离窗口中的文档拖放到其他窗口的标签栏；只有一个文档时直接移动现有窗口。
- 清理拖动取消时的标签图像，修正拖动图像列表的资源释放。

[下载 Windows x64 EXE](https://github.com/dengxibo/sumatrapdf-plus/releases/download/3.7.71/SumatraPDF-Plus.exe)。退出程序后替换完整安装目录中的 EXE，保留配置及配套文件；重启后生效。

## English

- Detach a tab into a full window as soon as it leaves the tab strip, then move the window with the mouse until release.
- Position detached windows on the monitor under the cursor and scale the tab grab offset for the destination display.
- Preserve tab reordering and allow dropping the detached document onto another window's tab strip. Move the existing window when it contains only one document.
- Clear the tab drag image when capture is cancelled and release its image-list resources correctly.

[Download Windows x64 EXE](https://github.com/dengxibo/sumatrapdf-plus/releases/download/3.7.71/SumatraPDF-Plus.exe). Close the application before replacing the EXE; retain settings and supporting files, then restart.
