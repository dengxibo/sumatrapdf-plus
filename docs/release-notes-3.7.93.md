# SumatraPDF Plus 3.7.93

## 中文

- 目录顶部“定位当前章节”按钮换用新图标：四角对焦框加中心点，线条粗细与相邻的展开、折叠按钮一致；按钮位置不变。

下载 Windows x64 EXE。退出程序后替换安装目录中的 EXE，保留配置及配套文件。

## English

- Replace the Locate Current Chapter icon at the top of the bookmarks sidebar with a four-corner focus frame and a center dot, drawn with the same stroke as the adjacent expand and collapse buttons. The button stays in the same place.

Download the Windows x64 EXE. Close the application before replacing the EXE; retain settings and supporting files.
