# SumatraPDF Plus 3.7.93

## 中文

- 目录顶部“定位当前章节”按钮换用新图标：三行目录加指向当前行的箭头，线条粗细与相邻的展开、折叠按钮一致。
- 定位按钮移到“全部折叠”按钮右侧，顺序为展开、折叠、定位、校准；侧栏过窄时仍只隐藏定位按钮。

下载 Windows x64 EXE。退出程序后替换安装目录中的 EXE，保留配置及配套文件。

## English

- Replace the Locate Current Chapter icon at the top of the bookmarks sidebar with list rows and an arrow pointing at the current row, drawn with the same stroke as the adjacent expand and collapse buttons.
- Move the Locate button to the right of Collapse All, so the order is expand, collapse, locate, calibrate. A sidebar that is too narrow still hides only the Locate button.

Download the Windows x64 EXE. Close the application before replacing the EXE; retain settings and supporting files.
