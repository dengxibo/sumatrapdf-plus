# SumatraPDF Plus 3.7.79

## 中文

- 修复删除下划线、波浪线、删除线等 PDF 文本标注时产生 BS property 错误（#119）。
- 错误窗口标题支持本地化；文本窗口支持 Ctrl+A 全选、Ctrl+C 和 Ctrl+Insert 复制，避免主窗口快捷键截获输入。

[下载 Windows x64 EXE](https://github.com/dengxibo/sumatrapdf-plus/releases/download/3.7.79/SumatraPDF-Plus.exe)。退出程序后替换完整安装目录中的 EXE，保留配置及配套文件，重启后生效。

## English

- Fix BS property errors when deleting PDF text markup annotations, including underline, squiggly and strikeout (#119).
- Localize the error window title and restore Ctrl+A, Ctrl+C and Ctrl+Insert in text windows, preventing document shortcuts from intercepting their input.

[Download Windows x64 EXE](https://github.com/dengxibo/sumatrapdf-plus/releases/download/3.7.79/SumatraPDF-Plus.exe). Close the application before replacing the EXE; retain settings and supporting files, then restart.
