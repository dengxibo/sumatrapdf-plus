# SumatraPDF Plus 3.7.113

- 修复单页／双页切换图标边缘混入白色的问题，避免深色主题下过亮、显粗。
- 图标线宽与相邻布局按钮保持一致，保留固定图案和双页按下态。

**新用户请先到 [3.7.107 发布页](https://github.com/dengxibo/sumatrapdf-plus/releases/tag/3.7.107)下载完整包，解压后用本版 EXE 替换其中的 SumatraPDF-Plus.exe。已有完整目录的用户只需替换 EXE，保留配置及配套资源。**

Fixes white antialiased edges on the single/double-page toolbar icon, especially in dark themes, and matches its stroke weight to neighboring layout icons. The fixed icon and double-page pressed state are preserved. New users can download a complete package from [3.7.107](https://github.com/dengxibo/sumatrapdf-plus/releases/tag/3.7.107), then replace its executable with this release's EXE.
