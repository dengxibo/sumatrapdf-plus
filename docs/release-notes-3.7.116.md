# SumatraPDF Plus 3.7.116 预发布

- 「选项 → 阅读 → 默认视图」新增「新 EPUB 使用连续双页视图」。默认开启。关闭后，新 EPUB 使用全局默认布局。
- EPUB 切换单页和双页时继续播放当前朗读，并尝试在重新分页后对齐高亮。欢迎反馈长篇 EPUB 在两个方向切换时的表现。

Windows 10 可继续使用系统语音和在线朗读。内置离线自然语音依赖 Windows 11 的语音运行时。Win10 用户可尝试 [NaturalVoiceSAPIAdapter](https://github.com/dengxibo/NaturalVoiceSAPIAdapter/releases/tag/v0.2.9-secv2-hd.3)，将兼容的普通离线音色添加到「系统语音」。HD 音色仍需要匹配的 Windows 语音扩展。

首次使用可先下载 [3.7.107 完整包](https://github.com/dengxibo/sumatrapdf-plus/releases/tag/3.7.107)，再替换 EXE。

English: New EPUBs can now follow the global default layout. Switching between single-page and facing layouts preserves active speech and remaps the highlight after EPUB repagination.
