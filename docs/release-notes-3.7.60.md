# SumatraPDF Plus 3.7.60

## 中文

- 修复部分 Word 文档的正文和目录中出现 heading_15 等内部书签名称的问题。
- 修复 Helvetica 等内置字体的多行自由文本批注仍缺失部分汉字的问题（#111）。换行不再错误触发日文字体回退。已有缺字批注需要进入编辑并提交一次，再保存，以重新生成完整外观。
- 修复 AI 对话输入框用方向键、Home/End 移动光标时文字暂时消失的问题。
- 修复主屏与副屏之间往返移动窗口后，AI 提示、输入框以及朗读条的倍速和“跟随”文字异常变大的问题。

[下载 Windows x64 EXE](https://github.com/dengxibo/sumatrapdf-plus/releases/download/3.7.60/SumatraPDF-Plus.exe)。退出程序后替换完整安装目录中的 EXE，保留配置、字典、OCR 模型及配套文件。

## English

- Fix internal bookmark names such as heading_15 appearing in Word document text and outlines.
- Fix missing Chinese characters in multiline free-text annotations using built-in fonts such as Helvetica (#111). Line breaks no longer incorrectly trigger Japanese font fallback. Edit and commit an affected annotation, then save, to regenerate its appearance.
- Fix text disappearing temporarily when using arrow keys or Home/End in the AI composer.
- Fix oversized AI hints, composer text, and read-aloud speed/follow labels after moving a window between monitors and back.

[Download Windows x64 EXE](https://github.com/dengxibo/sumatrapdf-plus/releases/download/3.7.60/SumatraPDF-Plus.exe). Close the application before replacing the EXE in an existing complete installation; retain settings and supporting files.
