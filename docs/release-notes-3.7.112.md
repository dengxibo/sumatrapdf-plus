# SumatraPDF Plus 3.7.112

- 工具栏新增单页／双页切换按钮，位于页面适配按钮与旋转按钮之间。固定分栏图标，按下态表示双页，普通态表示单页；切换保留连续滚动设置和当前阅读页。
- 修复 Mermaid Rust 静态库缺少 Windows 同步库依赖导致的 Actions 链接失败。

**新用户请先到 [3.7.107 发布页](https://github.com/dengxibo/sumatrapdf-plus/releases/tag/3.7.107)下载完整包，解压后用本版 EXE 替换其中的 SumatraPDF-Plus.exe。已有完整目录的用户只需替换 EXE，保留配置及配套资源。**

Adds a single/double-page toolbar toggle with a fixed split-page icon. The pressed state indicates double-page layout; switching preserves continuous scrolling and the current reading page. Also fixes missing Windows synchronization library dependencies in Actions builds. New users can download a complete package from [3.7.107](https://github.com/dengxibo/sumatrapdf-plus/releases/tag/3.7.107), then replace its executable with this release's EXE.
