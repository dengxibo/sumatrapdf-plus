# SumatraPDF Plus 3.7.56

## 中文

- 移除选项界面中过时的「使用浮动搜索窗口」开关；工具栏搜索与详细搜索入口仍可正常使用。

[下载 Windows x64 EXE](https://github.com/dengxibo/sumatrapdf-plus/releases/download/3.7.56/SumatraPDF-Plus.exe)。退出程序后替换完整安装目录中的 EXE，保留配置、字典、OCR 模型及配套文件。

语音适配器附件沿用上一版：[替换说明、许可证及对应源码](https://github.com/dengxibo/sumatrapdf-plus/blob/3.7.50/docs/release-notes-3.7.50.md)。这些附件为可选组件，不要放入 SumatraPDF 安装目录。

## English

- Remove the obsolete floating search window checkbox from Options; toolbar search and detailed search remain available.

[Download Windows x64 EXE](https://github.com/dengxibo/sumatrapdf-plus/releases/download/3.7.56/SumatraPDF-Plus.exe). Close the application before replacing the EXE in an existing complete installation; retain settings and supporting files.

Optional speech adapter assets are unchanged; see [instructions, licenses and source links](https://github.com/dengxibo/sumatrapdf-plus/blob/3.7.50/docs/release-notes-3.7.50.md).
