# SumatraPDF Plus 3.7.87

## 中文

- 详细搜索新增 BM25 相关搜索开关，可查找措辞不同但包含共同关键词的内容，按相关度展示最多 100 个候选段落。支持中文单字、双字和英文整词匹配，默认仍为精确查找。
- BM25 图标采用左侧 B、右上 25、右下 m 的组合，统一工具栏细线、主题颜色及选中样式，提示按界面语言显示。
- 修复中文搜索的 Unicode 空白判断，支持全角空格等字间空白；纯中文查询禁用大小写和全词匹配，避免旧选项导致漏查。
- 修复收藏夹长条目悬停提示反复激活、闪烁的问题。

下载 Windows x64 EXE。退出程序后替换安装目录中的 EXE，保留配置及配套文件。

## English

- Add optional BM25 related search in Detailed Search, ranking up to 100 candidate passages using CJK characters/bigrams and whole English words. Exact search remains the default.
- Add a theme-aware BM25 monogram icon and localized tooltip.
- Fix Unicode whitespace handling in Chinese search. Disable case and whole-word options for Han-only queries and ignore retained whole-word settings.
- Prevent repeated activation and flickering of tooltips for long Favorites entries.

Download the Windows x64 EXE. Close the application before replacing the EXE; retain settings and supporting files.
